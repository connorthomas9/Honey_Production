## Overview
In this project, we will attempt to investigate the decline in the population of honeybees and how these past trends may affect the future for honeybees by using a simple linear regression analysis

The primary analysis takes place in the `honey_production_notebook.ipynb` Jupyter Notebook file

The dataset used for this project is the `honeyproduction.csv` file, and comes by way of `Kaggle`

This project comes by way of `Codecademy.com` and has been recreated from scratch in order to demonstrate knowledge of applied usage of simple linear resgression models
